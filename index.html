1. Electronics from Zero

What is electronics?

Electronics is the study of controlling electrical energy using components such as resistors, LEDs, transistors, sensors and integrated circuits.

What is electric current?

Electric current is the rate at which electric charge flows through a circuit. Its unit is the ampere (A).

What is voltage?

Voltage is the electrical potential difference between two points. It is measured in volts (V).

What is resistance?

Resistance opposes the flow of electric current. It is measured in ohms (Ω).

Ohm's Law

V = I × R

Voltage = Current × Resistance

Example:

If a resistor is 100 Ω and the current is 0.02 A, the voltage across it is: 

V = I × R
V = 0.02 × 100
V = 2 volts

What is a circuit?

A circuit is a path through which electric current can flow. A simple circuit may contain a power source, connecting wires, a resistor and an LED.

What is GND?

GND means ground. In many low-voltage circuits, it is used as the reference point for measuring voltage and as the return connection for current.

2. Arduino Uno R3 Explained

What is Arduino?

Arduino is an open-source electronics platform. The Arduino Uno R3 is a development board based on the ATmega328P microcontroller.

You write a program on your computer, upload it to the board, and the microcontroller executes the instructions.

Major components of Arduino Uno R3

🧠 ATmega328P

The main microcontroller. It executes your program, reads inputs and controls outputs.

🔌 USB Port

Connects the board to a computer for programming and serial communication. It can also provide power.

⚡ Power Connector

Allows the board to receive power from a suitable external DC power supply.

🔢 Digital Pins

Pins 0–13 can be used for digital input or output. Pins 0 and 1 also serve serial communication.

📈 Analog Inputs

A0–A5 can measure analog voltages using the microcontroller's analog-to-digital converter.

〰️ PWM Pins

Pins 3, 5, 6, 9, 10 and 11 support PWM output, useful for controlling LED brightness and motor drivers.

🔋 Power Pins

The board provides 5V, 3.3V, GND, VIN and other power-related connections.

🔄 Reset Button

Restarts program execution. It does not normally erase the program stored in flash memory.

⏱️ Clock

The Uno R3 uses a 16 MHz clock source to provide timing for microcontroller operations.

🔗 ICSP Header

Provides SPI-related connections and can be used for programming the microcontroller with suitable tools.

How does Arduino actually work?

  1. You write code on a computer.
  2. The Arduino IDE compiles the code.
  3. The compiled program is uploaded to the board.
  4. The microcontroller stores the program in flash memory.
  5. After startup, the program begins executing.
  6. It reads inputs and changes outputs according to the code.
Important: The ATmega328P executes machine instructions, not the original human-readable C++ source code directly.

How does Arduino communicate with the computer?

When you upload a sketch, the Arduino IDE compiles it and transfers the program through the USB connection. On a typical Uno R3, a separate USB interface communicates with the computer and connects to the microcontroller's serial programming interface.

Digital versus analog input

A digital input detects a HIGH or LOW logic level. An analog input measures a voltage and converts it into a numerical reading.

On the classic Uno R3, the ADC is 10-bit, so analogRead() normally returns a number from 0 to 1023.

3. Arduino IDE

The Arduino IDE is the software used to write, compile, and upload Arduino programs.

How to start

  1. Install the Arduino IDE on your computer.
  2. Connect the Arduino Uno using a suitable USB cable.
  3. Open the Arduino IDE.
  4. Select Arduino Uno as the board.
  5. Select the correct serial port.
  6. Write or open a sketch.
  7. Click Verify to compile the sketch.
  8. Click Upload to transfer it to the board.

During uploading, the IDE compiles your source code into machine code and transfers the resulting program to the board.

4. Arduino Programming Basics

The basic program structure

void setup() {
    // Runs once after startup or reset
}

void loop() {
    // Runs repeatedly
}

What does setup() do?

setup() runs once when the program starts or the board resets. It is commonly used to configure pins and start communication.

What does loop() do?

loop() runs repeatedly after setup() finishes. It contains the actions that your program repeats.

pinMode()

pinMode(7, OUTPUT);

This configures digital pin 7 as an output. The microcontroller can then control its output logic level.

digitalWrite()

digitalWrite(7, HIGH);
digitalWrite(7, LOW);

HIGH sets the pin to its high logic level; LOW sets it to its low logic level. On the Uno R3, these are nominally 5V and 0V, respectively, under normal conditions.

delay()

delay(1000);

This pauses normal sketch execution for approximately 1000 milliseconds, which is one second.

Variables

int ledPin = 7;
int waitingTime = 1000;

Variables store values that your program can use. Here, ledPin stores 7 and waitingTime stores 1000.

Conditions

if (sensorValue > 500) {
    digitalWrite(7, HIGH);
} else {
    digitalWrite(7, LOW);
}

An if statement allows the program to make a decision based on a condition.

Loops

for (int i = 0; i < 5; i++) {
    // This block repeats five times
}

A for loop repeats a block of code according to its initialization, condition and update expression.

5. First Project: LED Blinking

Goal: make an external LED switch on for one second and off for one second.

Components required

  • Arduino Uno R3
  • One LED
  • One 330Ω resistor
  • Breadboard
  • Jumper wires
  • USB cable

Wiring table

Connection Connect to
Arduino pin 7 LED anode (+)
LED cathode (-) 330Ω resistor
Other end of resistor Arduino GND

Keep the resistor in series with the LED. Disconnect power before changing wiring.

Complete code

void setup() {
    pinMode(7, OUTPUT);
}

void loop() {
    digitalWrite(7, HIGH);
    delay(1000);

    digitalWrite(7, LOW);
    delay(1000);
}

Line-by-line explanation

  1. void setup() begins the initialization function.
  2. pinMode(7, OUTPUT) configures pin 7 as an output.
  3. void loop() begins the repeating function.
  4. digitalWrite(7, HIGH) sets pin 7 HIGH.
  5. delay(1000) waits approximately one second.
  6. digitalWrite(7, LOW) sets pin 7 LOW.
  7. The second delay keeps the LED off for approximately one second.
  8. The loop repeats, so the LED keeps blinking.

What happens electrically?

When pin 7 is HIGH, current can flow from the output pin through the LED and resistor to GND. The LED emits light. When pin 7 becomes LOW, the voltage across the series circuit falls and the LED turns off.

Experiment

  • Change delay(1000) to delay(500).
  • Observe how the timing changes.
  • Try changing the LED pin number in both the wiring and code.

6. Electronic Components

💡 LED

A light-emitting diode converts electrical energy into light. Polarity matters.

〰️ Resistor

Limits current and creates voltage drops. Its resistance is measured in ohms.

🔘 Push Button

A switch that opens or closes an electrical connection.

🌞 LDR

A light-dependent resistor changes resistance according to the amount of light it receives.

🌡️ DHT11

A digital sensor that measures temperature and relative humidity.

📏 Ultrasonic Sensor

Sends ultrasonic pulses and measures their return time to estimate distance.

🔔 Buzzer

Produces sound when driven according to its type and electrical requirements.

🔄 Servo Motor

Uses control signals and internal feedback to move towards a target position.

Important principle

Arduino pins are designed for low-current signals. Motors and other high-current loads generally require suitable driver circuits and an appropriate power supply.

8. Common Problems and Solutions

Arduino board not detected

Check the USB cable, USB connection, selected port and any required board drivers.

Compilation error

Check spelling, brackets, semicolons, library installation and the complete error message.

LED is not glowing

Check LED polarity, resistor connections, GND, pin number and whether the program uploaded successfully.

Serial Monitor shows strange characters

Check that the Serial Monitor baud rate matches the baud rate used by Serial.begin() in your program.

Board repeatedly restarts

Check the power supply, wiring and whether a connected component is drawing too much current.
